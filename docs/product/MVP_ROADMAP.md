# MVP roadmap

| Order | Module | Milestone |
| --- | --- | --- |
| 1 | Authentication | M1 Secure Multi-Tenant Foundation |
| 2 | Tenant membership | M1 |
| 3 | Roles and permissions | M1 |
| 4 | Tenant settings | M1 |
| 5 | Customers and contacts | M1 schema and basic customer workflow |
| 6 | Service locations | M1 |
| 7 | Equipment and assets | M1 |
| 8 | Leads and service requests | M2 Service Intake |
| 9 | Dispatch and jobs | M3 Operations |
| 10 | Calendar and appointments | M3 |
| 11 | AI receptionist calls and outcomes | M4 Voice Intake |
| 12 | Tracked human handoffs | M4 |
| 13 | Estimates and follow-up | M5 Follow-up |
| 14 | Revenue recovery reporting | M6 Reporting |

Current build is M1. Each milestone requires Architect contract review, Quality workflow/security review, DevOps check evidence, and coordinator acceptance. Production release separately requires explicit owner approval. M1 is not accepted until live Supabase isolation/auth and authenticated E2E are verified.

Contact editing, self-service invitations, password reset, assignment-scoped technician views, live voice, and reporting are follow-up work. Provider decisions wait until the matching milestone.
