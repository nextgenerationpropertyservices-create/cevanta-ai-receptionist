- Durable identical retries across all commands are now explicit. Compute digest only in SQL from normalized canonical jsonb::text plus fixed scope-v1/command/all arguments; do not compare a server-generated digest with a different serialization or accept a client hash. Retention has no expiry/delete path in this slice. Digest/private receipt is not anonymized data or a browser-readable resource.
- Reauthorize current member and tenant-scoped target visibility before returning receipt; then replay precedes stale expectedVersion and invalid-current-timezone checks. Identical lost-response retry must reuse original request/expectedVersion; changed normalized inputs under that request return request_reuse. Replay returns original id/version, not newest record state; UI refresh obtains current authorized content. Matching submission with a different actor/request returns submission_reuse, never another actor's receipt/content. Concurrent duplicate reservation and unique collisions must remain inside transaction rollback semantics.
- Membership first, timezone tenant lock where applicable, request advisory lock, creation submission lock, aggregate/ordered parent locks, child lock, then mutation/audit/receipt gives an implementable consistent order. Advisory collisions are serialization keys only; exact scoped receipt/submission predicates establish identity. No implementation may enter child-first or reverse advisory/aggregate order. Membership locking may delay provisioning; transactions must remain bounded and provider-free. Multi-connection testing must verify the actual implementation order rather than trusting sequential mocks.
